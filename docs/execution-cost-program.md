# Исполнение и модель издержек: программа измерений

Приоритет оператора 30.09.2026: улучшить исполнение и модель издержек на ИЗМЕРИМУЮ
величину. Итог ночи отпечатков (`algo-footprints-registry.md`): торгуемого чужого
алгоритма нет, но микроструктура предсказуема (активность на границах часа, очередь
L1, глубина), а наш тейкер платит 9-12 пт за филл на RI. При обороте живого робота
это самый крупный измеренный рычаг.

## Что измеряем и в каких единицах

Единица — пункты цены за филл и рубли в месяц при текущем обороте живых роботов.
Любое улучшение = «было X пт/филл, стало Y, разница × число филлов в месяц × ₽/пт».

## Шаги

0. **Базовая линия по живым филлам** (`scripts/fills_vs_model.py`, расширить): по всем
   46 дням и роботам: цена филла против mid на момент отправки (пункты, знак «хуже для
   нас»), задержка PENDING→FILLED, доля неисполненных, разрез по часу дня, объёму,
   роботу, стороне; итог в ₽/месяц при текущем числе филлов. Это число, которое
   уменьшаем.
1. **Поверхность издержек** (`trader/lab/exec_cost.py`, i9): по полной выжимке стакана
   спред и цена прохода рынком N лотов (1, 2, 5, 10, 20) в пунктах от mid, медиана и p90
   по минуте дня и по секунде внутри минуты (границы часа из A4: дорожает ли :00),
   RIZ6/SiZ6/GDZ6. Ответ на «когда входить дорого».
2. **Политики доведения** (`trader/lab/exec_policy.py`, i9): на случайных моментах,
   стратифицированных по классу минуты (граница/событие/прочее) и по объёму: «сразу
   рынок» против «лимит у планки, ждать T с, потом рынок» (T = 5, 10, 30, 60, 180) и
   «лимит + погоня». Наливка по снимкам без позиции в очереди даёт ГРАНИЦЫ: оптимистично
   (встречный best дошёл до нашей цены) и пессимистично (цена прошла наш уровень
   насквозь). Выход: ожидаемая цена филла по политике с границами, доля неисполненных,
   неблагоприятный ход при ожидании. Это прямой ответ, какие hold/chase ставить в профиле.
3. **Модель очереди по ленте** (после 2-3 недель мс-ленты): позиция в очереди по номеру
   сделки и объёму уровня, честная наливка пассивной заявки; сужает границы шага 2.
4. **Передача real-trade**: рекомендованные секунды фаз профилей и минуты, где вход
   дорог, с цифрами шагов 0-2. Настройки живого робота меняет только real-trade.

## Правила

Считать на i9 (kind=task), кроме потоковой подготовки данных на хостере под nice.
Каждая цифра рядом с ценой круга и числом филлов. Границы, а не точечные оценки, пока
нет модели очереди. Вывод только после проверки fable.
