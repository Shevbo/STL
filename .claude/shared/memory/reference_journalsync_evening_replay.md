06.08.2026: реальный робот lxk22 (macd_shectory1, мартингейл) разошёлся с QUIK
на 7 контрактов (вера +3, биржа +10), реализованный P&L испорчен. С 19:23 по
19:33 journal auto-heal (`internal/runner/journalsync.go`) минута за минутой
вливал в книгу раннера ВЧЕРАШНИЕ вечерние филлы как «потерянные».

**Корень:** QUIK штампует сделки вечерней сессии (19:05+) датой СЛЕДУЮЩЕГО
торгового дня. Вчерашние 19:2x весь день читались как «сегодня 19:2x» —
будущее, гарды молчали; когда часы прошли это время + 90с, сделки стали
«свежими непокрытыми» и захилились. Дедуп по qsync-cid не ловит: вчера те же
сделки применились под обычными rr:-cid. Гард среза 200-хвоста тоже слеп:
судит по «старейшая запись до полуночи», а подставные датированы вечером.

**Фикс:** floor/age в MissingFills — по БИРЖЕВОМУ времени (`ExchTsMs`), откат
на штамп QUIK только когда биржевого нет. Rev 1786043766.

**How to apply:** любой session-скоуп по времени сделки QUIK обязан помнить:
дата сделки QUIK = ТОРГОВЫЙ день, не календарный; вечер живёт в завтра.
Честное время — ExchTsMs из Lua (cc3+). Диагноз такого класса: в детальном
логе робота фантомные FILL с ценами вчерашнего рынка и секундами цикла (:08).
Лечение позиции: пауза → align fix_state с локальной консоли агента (сделано
оператором 22:12, позиция←7 @ 88964). «Реализовано» раннера после такого
недостоверно; честный P&L — в algo_trades (его дедуп фантомы не пропустил).
