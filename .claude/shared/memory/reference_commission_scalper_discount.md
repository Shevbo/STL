`trader/lab/commission.py` берёт полную taker-ставку с КАЖДОГО филла. MOEX
берёт меньше со скальперской части (позиция открыта и закрыта внутри сессии),
поэтому модель завышает сбор тем сильнее, чем чаще стратегия крутит.

Замер по RIU6, модель против факта QUIK (`ts_comission`, из
`~/stl-day-close.log`): 23.08 — 351 против 375 (38 лотов, доля 1.07);
24.08 — 3758/2908 (0.77); 26.08 — 4162/2159 (0.52); 02.09 — 2890/1275 (0.44);
03.09 — 2642/1339 (0.51). Факт включает ещё и ручную торговлю оператора, то
есть по роботам расхождение больше.

Цена ошибки: у живого lxk22 за жизнь начислено 87 707 ₽ комиссии, по факту
около половины — примерно 40 тысяч, которых нет в его «итого фикс». В
сравнении стратегий ошибка НЕ нейтральна: наказывает высокочастотные.

Дневное число панели этим больше не задето (с 05.09.2026 «сегодня» валовое,
сборы отдельной строкой из QUIK) — задеты «итого фикс», лидерборд и бэктест.
Зона окна backtests, передано письмом 05.09.2026.
