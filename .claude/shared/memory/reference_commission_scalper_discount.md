`trader/lab/commission.py` берёт полную taker-ставку с КАЖДОГО филла. MOEX
берёт меньше со скальперской части (позиция открыта и закрыта внутри сессии),
поэтому модель завышает сбор тем сильнее, чем чаще стратегия крутит.

Замер по RIU6, модель против факта QUIK (`ts_comission`, из
`~/stl-day-close.log`): 23.08 — 351 против 375 (38 лотов, доля 1.07);
24.08 — 3758/2908 (0.77); 26.08 — 4162/2159 (0.52); 02.09 — 2890/1275 (0.44);
03.09 — 2642/1339 (0.51). Факт включает ещё и ручную торговлю оператора, то
есть по роботам расхождение больше.

Цена ошибки: у живого lxk22 за жизнь начислено 87 707 ₽ комиссии, по факту
около половины — примерно 40 тысяч, которых нет в его «итого фикс». В
сравнении стратегий ошибка НЕ нейтральна: наказывает высокочастотные.

Дневное число панели этим больше не задето (с 05.09.2026 «сегодня» валовое,
сборы отдельной строкой из QUIK) — задеты «итого фикс», лидерборд и бэктест.
Зона окна backtests, передано письмом 05.09.2026.
Связано: [[reference-commission-model]], [[reference-vm-split-account]].

Дополнение 01.10.2026: комиссия в журнале `algo_trades` это НЕ факт, а расчёт `commission.py`
(`trader/quik/algo_ledger.py:291-313`), скидка скальпера там только на закрывающую ногу: 7.5-7.8
₽/лот на филл RI; бэктест даёт скидку на обе ноги: 5.2; полный тейкер ~9.9. Единственный факт:
биржевой сбор по счёту из QUIK (`ts_comission`, снимок 23:52 в `~/stl-day-close.log`): 3.6 ₽/лот
в будни 23-30.09 (2.0-5.5 по дням), с брокером 0.45 около 4.05; суббота 2.36 (удвоение выходных
не подтверждено). Сверка «бэктест против журнала» = модель с моделью: 01.10 я принял её за
занижение комиссии на 25-33% и отозвал. Ошибка в ₽/мес: бэктест lxk22 +5.2 тыс, журнал +15.8 тыс.

ВАЖНО, оператор 01.10.2026: «никаких скидок ни биржа, ни брокер не дают». Значит
`SCALPER_DISCOUNT = 0.5` в `commission.py` (и скидка в `algo_ledger`) это НЕ правило биржи, а
подгонка real-trade под наблюдённое отношение факт/модель (0.44-0.61 в активные дни). Факт по
счёту при этом всё равно ниже полного тейкера (3.6 против ~9.45 ₽/лот биржевой части на RI):
причина не установлена (доля мейкерских филлов, ставка в модели, неполнота `ts_comission`).
Не называть это «скальперской скидкой» в докладах оператору. У real-trade запрошены комиссии
по каждой сделке из QUIK (exchange/clearing/tech_center/broker_comission) в журнал сделок;
после недели данных калибровать `commission.py` по факту одним коммитом для бэктеста, бумаги и
журнала. Ошибку реализации скидки на переворотах до этого не чинить.
