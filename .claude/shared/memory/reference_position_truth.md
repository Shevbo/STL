Вопрос «что сейчас в рынке» отвечается ТОЛЬКО так:
`ssh hoster 'cd ~/apps/shectory-trader && python3 scripts/pos.py'`
(сделки за день: `python3 scripts/pos.py --trades [YYYY-MM-DD]`).

Источник — `data/truth.json`, который STL пишет раз в 2 с (`trader/quik/truth.py`),
плюс журнал `data/trades/YYYY-MM-DD.jsonl` (дедуп по номеру сделки, переживает
рестарт STL и обнуление ринга агента на 500 сделок).

**Чего делать нельзя:** отвечать про позиции по `data/smart_orders.json` и по
журналу `journalctl -u shectory-trader`. Книга хранит НАМЕРЕНИЯ оператора; закрытие
позиции нативной стоп-заявкой QUIK в неё не попадает — 23.09.2026 отчёт по книге
назвал открытым шорт 40 RIZ6, закрытый полутора часами ранее.

Шапка вывода: `СВЕЖО` / `СТАРО` + причина. `СТАРО` = единственный честный ответ про
позиции «не знаю». Свежесть судит heartbeat ЛИНКА, а не возраст зеркала: агент шлёт
статус только при изменении содержимого, поэтому в спокойный час зеркалу законно
десять минут. Отдельно ловится замерший сборщик статуса (линк жив, зеркало стоит).

Фактическая картина живёт в памяти STL (`trader/quik/store.py`) и наружу отдаётся
лишь через API с сессионным токеном — у агента этого токена нет, и рестарт STL
стирает память. Файл-снимок и есть обход этой слепоты.
