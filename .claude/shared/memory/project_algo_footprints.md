(алготрейдеры, манипуляторы), скользящие средние — лишь примитивный пример.

модуль на гипотезу `trader/lab/footprints/<id>.py` с `run(arg: dict)`, считает i9 (kind=task).

25.09 12:44-27.09 00:02), котировки bid/ask/last 50 дней, лента ТОЛЬКО 25.09 (поток
встал, чинит real-trade). Полные выжимки для i9: `agent_bars/book<КОД>f0929.json`
(ts_ms), лента `tape<КОД>d0925.json`.

C6, D1, E1. Механика ниже издержек: C1 (очередь L1), C4 (истощение L1), D2 (импакт принта),
D3 (ловушка last). След есть: A4 (h:00/h:30 объём 1.6-2x, в выходные на Si, не новости).

**Why:** оператор хочет широкий перебор гипотез субагентами, а не одну ось; окно бережёт
токены под замысел и проверку fable.

**How to apply:** новая гипотеза = строка реестра + модуль по каркасу + Sonnet-задача по
протоколу (контроль внутри дня, вторая половина данных, цена круга рядом с эффектом),
вывод только после проверки fable. Закрытые: A1 (кроссы средних = след прошедшего хода),
B1 на M1 close = bid/ask-отскок. См. [[project-retro-reverse]], [[reference-impulse-news-traps]].
