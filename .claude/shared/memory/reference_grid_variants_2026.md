02.10.2026, все на RI 2026 (Si справочно), grid_sim/footprints, отбор на 2/3 дней, проверка на последней трети:
- Широкая сетка (`docs/grid-radiation-wide-2026.md`): высота = размах 6+ мес до старта, до 30 уровней,
  многодневная. Si C2 N=30 +76/+27/+3 тыс по стартам 01.07/01.08/01.09, RI +265/+102/+10 (ГО до 629 тыс,
  просадка до 320), BR/GD в минусе (данных мало). Ни один набор не обогнал пассивную позицию той же
  экспозиции в сторону рынка; три старта в одной фазе.
- По расписанию дня (6-я редакция): направленность окон 0.35-0.59, самое боковое 09-11, самое трендовое
  14:30-17:30; ранг стабилен только на крупной разбивке (корр. половин +0.59), скользящие 60/120 мин нет.
  Сетка шаг 400 только в 09-11: проверка +26 тыс против −12 дневной, лучше случайных окон 20/20, но 21
  из 26 на RIU6, на обучении минус.
- Короткая сетка сразу после импульса (`docs/flex-radiation-2026.md` 2б), tf M1/M5/M15/H1: возвратность
  после импульса как у случайных моментов той же волатильности; 0 положительных на обучении.
- «Гибкая радиация»: боковик после крупного импульса короче (см. [[reference-post-impulse-volatility]]).
- «Анти-драма» (`docs/anti-drama-2026.md`): фейд импульсов 15+ ATR, M1: продолжение −13 тыс, откат
  лучше случайных 20/20, но +5 ₽/лот на сделку, t 0.24, плюс на 2 контрактах из 4.
- 3-я (опоздание входа + перенос базы) и 4-я (сброс по импульсу) редакции закрыты; 5-я = защита
  ([[reference-grid-rearm-kills-protection]]).

**How to apply:** новые идеи сетки сравнивать с этими базами; единственное работающее в бою: защита без
перевзведения. См. [[reference-grid-radiation-closed-ri]].
