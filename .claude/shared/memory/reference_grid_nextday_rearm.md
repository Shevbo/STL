Непрерывная многодневная сетка в боевой семантике (позиция через ночь, база не сдвигается до защиты;
grid_sim `simulate_nextday`/`run_nextday` fe2f37f, `docs/grid-regime-filter-2026.md` 7-я редакция).
Живые наборы на отложенной трети: без защиты −198/−260/−246 тыс; боевая защита + перевзвод утром
−22/−18/−17; выбранная на обучении поклёвка (уровень 2, одно касание) −10/−1.6/−1.6; обучение −91..−119.
Чувствительность к задержке D нерегулярна (D=30 плюс, D=0 и 10:00 минус 35-48) = шум. Дневная модель
5-й редакции (сетка каждое утро в 10:00, флэт 23:40) уже была «перевзвод утром», это стоит помнить.
Оператор: порог поклёвки задавать номером уровня, не процентом ([[project-grid-protection-trigger]]).

**How to apply:** перевзвод сетки любой (15/60 мин, утром) плюса не даёт; работает только «меньше
набирать». См. [[reference-grid-rearm-kills-protection]], [[reference-grid-variants-2026]].
