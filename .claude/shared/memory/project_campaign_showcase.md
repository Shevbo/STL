04.10.2026 оператор заказал страницу в домене бэктеста: ВСЕ проведённые кампании карточками (название, идея, миниатюра кривой P&L, статус, net/сделки/просадка, метка «ред. N из M»), по клику подробный отчёт лидеров с большим графиком, у каждой кампании свой вечный URL. Работа разделена между окнами, спека `docs/campaign-showcase-spec.md`: **backtests** ведут реестр `docs/campaigns/registry.json` (на 04.10 — 36 кампаний, 25 линий, все `kind=research`, `unit=rub`, `status_hint=done`) и сборщик `scripts/campaign_showcase_build.py`, который кладёт `data/campaign_showcase/index.json` и `<slug>.json`; **ui-ux** отвечает за маршруты, страницу, график, API и выкладку. Формат полей фиксирован в спеке, изменения только письмом.

**Решения ui-ux.** Данные читаются ФАЙЛАМИ read-only с кэшем по mtime (`trader/api/lab_showcase.py`, как `quik_limits.json`), не таблицей: сборщик пишет всё целиком, построчных правок нет. Маршрут путевой `/backtest/campaigns[/<slug>]`: nginx уже отдаёт `index.html` на ЛЮБОЙ путь, правка сервера не нужна (проверено на несуществующем пути; в Git Bash curl-пути ломает MSYS, нужен `MSYS_NO_PATHCONV=1`). Query-форма `/?lab=campaigns&c=<slug>` жива для старых ссылок. Slug — это имя файла из URL, поэтому проверяется регуляркой `^[a-z0-9][a-z0-9-]{0,127}$`, иначе это путь чтения. Нет `index.json` — API отвечает `available:false` с причиной, битый файл не применяется.

**График как в TSLab: цвет меняется строго на y=0.** Не градиентом и не `clipPath`, а разрезом кривой в точках пересечения нуля с линейной интерполяцией (`splitAtZero` в `frontend/src/lib/campaign-showcase.ts`): каждый кусок лежит по одну сторону оси и красится своим цветом, поэтому «зелёное под нулём» невозможно; инвариант проверен тестом на синусоиде. Нулевая ось входит в диапазон всегда, иначе кривая целиком выше нуля выглядела бы «в плюсе с самого начала». `EquityChart` не подошёл: он рисует несколько роботов по журналу на uPlot с осью ГО.

**Открыто на 04.10.2026:** единица времени в `[ts, pnl]` не зафиксирована (различаю по величине, `< 1e11` — секунды); в карточке `index.json` нет `kind`, `unit`, `symbols` (без них нет метки «исследование», подписи единицы на миниатюре и фильтра по инструменту) — запрошены письмом; страница не проверена на настоящих данных, сборщика ещё нет; для API нужен рестарт `shectory-trader` (за real-trade).
