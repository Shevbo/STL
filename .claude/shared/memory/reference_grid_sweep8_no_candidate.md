`docs/grid-radiation-sweep-2026.md`, grid_sim `simulate_sweep` 9243445f, i9 sweep8c (~6 ч). Проверка на последней
трети: 3 мес RI +22 тыс, GZ +3, Si −6, SR −0.3, GD/BR в минусе; 6 мес все шесть в минусе. Оптимум на краю
сетки. Первый прогон считал тейк от СРЕДНЕЙ позиции (trades_pnl), а не по закрытым парам уровней: поймал
fable, знаки на 3м перевернулись при переотборе. rand-контроль с принудительным закрытием смещён вниз:
Q2 по нему слабое свидетельство, смотреть голую сетку. Шаг оператор велел задавать долей недельного размаха.
Оператор: порог поклёвки номером уровня.

**How to apply:** новая идея сетки с тейком = парный учёт; сравнение через голую сетку, не только rand.
