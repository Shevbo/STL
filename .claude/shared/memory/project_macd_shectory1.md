`macd_shectory1` «MACD trend Shectory1» — копия живого MACD trend A (macd_cross,
RIU6, fast=57/slow=48/signal=10, tp_atr=4, avg_max=34, avg_step_atr=21, avg_atr_n=25)
отдельным id, чтобы прод-робот не менял поведение. Коммиты a4e3f88 + ec815f0 (31.07.2026).

Три параметра в общем слое `make_on_bar`, все выключены по умолчанию:
- `nd_days` — окно в торговых днях; амплитуда = max(high) − min(low) по ЗАВЕРШЁННЫМ дням.
  Кольцо дневных hi/lo ведётся ИНКРЕМЕНТАЛЬНО в состоянии робота (`amp_ring`): запрос
  20 000 минуток на каждом баре убил бы перебор и раннер, как когда-то pivot.
- `gap_auto` — разножка = амплитуда / avg_max вместо `min_gap_pts`.
- `k_avg` (×10) — каждый следующий добор = предыдущий × k_avg, округление ПОЛОВИНЫ ВВЕРХ
  (банковское round дало бы 2→3→4→6 вместо 2→3→5→8).

Прогон 01.06-31.07.2026, RIU6, 252 комбинации: `/?campaign=camp-20260731-shectory1w`.
База (разножка 220 + k_avg=1.0, точная копия живого конфига) = −6 275 ₽. Лучшие по
деньгам: авто nd=5 / k=2.5 -> 529 393 ₽ (RF 4.9). Лучшие по устойчивости: авто nd=14 /
k=3.0 -> 355 196 ₽ при RF 12.7 и MAE 30 857. В минусе всего 6 из 252 — признак удобного
окна, а не хорошей стратегии; walk-forward НЕ считался.

Ловушка: прогрев у этой стратегии в 4 раза длиннее, чем у macd_cross — см.
[[reference-macd-warmup-frozen-signal]]. Поэтому напрямую с живым MACD trend A её
результаты сравнивать нельзя.
