Вопрос оператора «кандидат в реал?» по ссылке на кампанию stp GDM6 bollinger_bo_m1.
Лидер: period 29, mult 3.0, усреднение avg_max 7 шаг 0.6 ATR, ставки +2, суперусреднение.
Выглядел лучшим за всё время: GDM6 +697k (золото −12.9%), GDU6 +132k (+4.4%), __inv в минусе
на обоих — «направление есть». Но GDM6 по маю–июню пересекался с окном отбора (GDU6 03.05–07.08).

Вне выборки (queue_gd_bollinger_oos.py, gdo, критерий в коммите до запуска), GDM5/GDU5/GDZ5/
GDH6 — все на росте золота +9…+19%, flatten_end=1. База sl0 в рублях: +18k / −412k / −516k /
−30k → плюс 1/4, сумма ≈ −0.94 млн ₽ до спреда. __inv тоже минус 4/4 → на росте у сигнала
нет направления, обе стороны платят издержки. НЕ КАНДИДАТ. Проверено fable.

**Ловушка единиц.** У истёкших контрактов 2025 point_value в метаданных нет → движок считает
1.0 → P&L в ПУНКТАХ; у GD пункт = 84.26 ₽ (8.42569 ₽ за шаг 0.1, фактически курс USD/RUB на
дату, ±10-15% за год). Биржевая комиссия масштабируется вместе с P&L (rate × price × pv), при
пересчёте ×84 она уже учтена; не хватает только брокерской фиксированной (<1%) и спреда.
Признак: max_mae в сотни пунктов при цене ~3500 = пункты; 68k = рубли.
Деньги для реала на будущее: ГО GD ~30-33k ₽/контракт, лестница до 7 = ~230k ГО.
