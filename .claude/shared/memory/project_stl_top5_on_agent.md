Топ-5 по итогу бумаги STL (фикс + открытая позиция); bollinger_bo BRN6 исключён — его позиция −21 на
истёкшем BRV6, итог неизвестен. Развёрнуты на агенте 9618 БУМАГОЙ (paper=true), параметры 1:1 из STL,
BR перенесён с BRX6 на BRZ6 (BRX6 нет в ленте агента), старт во флэте, 600 баров прогрева на месте:

| stl5-ob-BRZ6 | paper-order_block-BRN6 | order_block | 93 |
| stl5-fvg-RIZ6 | paper-fvg-RIM6 | fvg | 38 |
| stl5-bollbo-BRZ6 | paper-bollbo-BRU6-v2 | bollinger_bo_m1 | 11 |

| stl5-2ema-RIZ6 | UNI-2ema-RIU6 | shectory_2ema | 100 |

**max_position выставлен ради верности бумаги (qty × (avg_max+1), у 2ema 100) — это НЕ безопасный
предел для реала.** Перед любым армингом пересчитать по [[reference-agent-caps-backstop]] и
[[reference-robot-perorder-cap-trap]].

**Срез STL на момент переноса (realized в пунктах, позиция):** order_block 500.93 пт BR, позиция 0;
fvg 230 290 пт, −9 по 84827.78; bollbo 181.833 пт BR, −5 по 99.5773 (BRX6); Bollinger Si 67 616 пт,
+64 по 84716; UNI-2ema 54 039 пт, −3 по 85046.67. В среду сравнивать ПРИРОСТ STL от этого среза с
результатом stl5-* за те же дни (ledger, net с комиссией), а не накопленное с начала.

**Почему это важно:** у трёх стратегий уже есть агентские двойники с другими параметрами, и разрыв
огромный (fvg: бумага STL +377 тыс против агентских −84/−44 тыс). Бумага STL наливает по close без
стакана и без комиссии — [[reference-paper-robots-optimism]]. Перенос даёт честную наливку на тех же
параметрах.
