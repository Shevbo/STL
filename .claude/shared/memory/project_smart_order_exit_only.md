02.10.2026 оператор заказал кнопку «только на выход» у РУЧНЫХ умных заявок со своей позицией (радиация, коридор, треугольник) и определил её смысл одной фразой: **«это значит выход без убытка»**. Заявка перестаёт открывать и закрывает свою позицию только по цене не хуже средней входа. Ручка `POST /api/v1/quik/smart-orders/{so_id}/exit-only {on}`, флаг `exit_only` в книге, экран сделан окном ui-ux (`fb63cf2`).

Отличие от такого же режима у РОБОТОВ ([[exit-only-mode]], 28.07.2026): там выход идёт по сигналу стратегии и цена не проверяется, здесь выход идёт уровнями — цену проверяем.

**Ради этого завелась средняя цена позиции (`g_avg`, `c_avg`), которой у умных заявок не было вовсе.** Без неё на вопрос «это выход без убытка?» ответить нечем. Считается там же, где позиция, одной формулой `blend_avg`: доливка взвешивает по объёму, сокращение не трогает, переворот через ноль делает средней цену новой стороны, выход в ноль обнуляет. Считает ТОЛЬКО филлы этой заявки, не нетто счёта.

**Ловушка, пойманная на живых деньгах в тот же день:** филл может прийти БЕЗ цены, и такие нули утянули среднюю сетки `67c52ac651` к **14211** при филлах 85270..86080 — в шесть раз мимо. С такой средней режим заблокировал бы ЛЮБОЙ выход, потому что все цены «хуже средней». Теперь позиция считается всегда, а средняя трогается только по настоящей цене.

**Гейт отказывает ТРЕМЯ разными причинами и каждую пишет в журнал** (`held`, текст «только на выход: …»): позиции нет; уровень доливает, а не сокращает; цена хуже средней. Молчать нельзя ни в одном — включённый режим выглядит как «заявка ничего не делает», и оператор обязан уметь объяснить тишину. У коридора объём дополнительно урезается РОВНО до позиции, без удвоения на переворот.

**КОМИССИЯ НЕ УЧТЕНА:** равенство средней даёт ноль ДО сборов, с ними небольшой минус. Оператору сказано; отступ в пунктах сверх средней заводить только по его слову.

**Что ждёт реализации (спецификация окна backtests, решение оператора 02.10, он ответил «да»):** автоматический триггер защиты сетки — исполнено 3 уровня ИЛИ цена ушла от `g_base` на 0.25%; после триггера новые заявки не ставятся, стоящие входные снимаются, позиция закрывается по средней. Числа бэктеста: убыток на отложенной трети сокращается в 11-15 раз (−288/−399/−366 → −23/−27/−27 тыс ₽), закрытий по безубытку 81%, по стопу 7%. Прибыльной сетку это не делает, это ограничитель ущерба. Параметры в карточке, по умолчанию 3 и 0.25%, 0 = выкл.

**СМЫСЛ УТОЧНЁН ОПЕРАТОРОМ 02.10.2026 16:53:** «только на выход — это выход только из текущей позиции
без убытка, а не по накопительному результату». У сетки это теперь ОДНА заявка: закрывающая сторона,
объём |g_pos|, цена `breakeven_price` — средняя ТЕКУЩЕЙ позиции (g_avg), округлённая в сторону без
убытка; рынок уже лучше — выход сразу, ценой в полколлара за рынком. Все уровни снимаются. До этого
выход шёл уровнями «не хуже средней» и на RIZ6 при +9 по 84930 стоял на 85020/85110/85200 — ждал
прибыли, которой не просили. Коридор (стенки) пока по-старому.

**Два бага того же дня в этом пути, оба в бою:** (1) уровни проверялись поштучно, суммы не было —
GZZ6 при +5 держал 110 контрактов продаж, рост открыл бы шорт −105; (2) после перехода на одну
заявку сторож за секунды поставил СЕМЬ продаж 9 при +9 — см. [[reference-terminal-table-lags-order-store]].
