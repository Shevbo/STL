02.10.2026 проверка «гибкой радиации» (`docs/flex-radiation-2026.md`, модуль
`trader/lab/footprints/flex_range.py` a06903c, RIH6-RIZ6 + SiU6 2026): длина боковика после импульса
(первое закрытие вне полосы ±k ATR вокруг close пика, ATR = средний размах минуты за 60 баров до
старта импульса, цензура по Каплану-Мейеру) ПАДАЕТ с высотой импульса на всех контрактах. P2 k=3,
корзины 3-5 / 5-8 / 8-12 / 12-25 ATR: RIU6 11 / 8 / 4 / 2 бара против 11 у случайных моментов;
RIM6 10/7/5/3 (11); SiU6 10/7/4/2 (12); k=6 то же (RIU6 41/27/13/4 против ~40). Наклон log L на
log H −0.5..−1.1 против ~−0.05 у контроля. Полоса, пропорциональная высоте импульса, даёт ложный
рост L по геометрии.

**Why:** гипотеза оператора «после бури затишье пропорционально буре» опровергнута; это
кластеризация волатильности (ATR до импульса занижает текущий размах).

**How to apply:** любые сетки/возвратные схемы сразу после импульса попадают в самый
волатильный участок; осмысленный вариант наоборот: запуск только после N баров тишины. Полосы
для «длины боковика» брать фиксированными в ATR, не пропорциональными высоте события, и всегда с
контролем случайных моментов. См. [[reference-grid-radiation-closed-ri]], [[project-retest-strategy]].
