Доли и медианы по сетке перебора недействительны, пока не сосчитаны РАЗЛИЧНЫЕ
исходы. 22.09.2026 сетка на 2880 наборов (40 дней, стакан) дала 626 различных
исходов на RIU6 и 102 на RIZ6 — «плюсовых 93%», «медиана +2545» были счётом копий.

Два источника дублей в macd_shectory1:
- объём добора целый, next_add = int(prev × k_avg + 0.5): при qty=1 любое
  k_avg < 1.5 тождественно 1.0 (960 пар из 960 идентичны по net И по сделкам);
- тейк выше ~8×ATR не достигается: tp_atr 80/120/200 идентичны во всех 720 парах.
  Тот же признак ловит инертный стоп (sl 3% == 4% на RIZ6 — не сработал ни разу).

**Why:** дубль не врёт в своей строке — он врёт в статистике по сетке, перевешивая
медиану и долю плюсовых в сторону того значения, у которого больше копий.

**How to apply:** `PYTHONPATH=. python scripts/grid_degeneracy.py --base <кампания>`
ПЕРЕД любым выводом по перебору; генератор `queue_today_sweep.py` сворачивает
мёртвый k_avg сам. Признак «совпали net И число сделок» здесь означает дубль оси,
а не мёртвую ось из [[reference_i9_axis_alive_probe]]. Связано с
[[reference_direction_not_edge]] — второй слой той же ошибки: сетка наследовала
расписание сторон живого конфига.
