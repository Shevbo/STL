Замер 05.08.2026, ОДИН движок, одни бары, одна комиссия (сломанная версия
воспроизводится подстановкой старой формулы прогрева в `REGISTRY[...]["warmup"]`
ДО вызова `make_on_bar` — он захватывает её при сборке). Конфиг живого
MACD trend A на RIU6, qty=2, avg_max=34, tp_atr=4:

| 20.07-05.08 | починенная | +56 630 ₽ | 0 | 68 019 ₽ | 1417 |
| 01.06-05.08 | сломанная | **+41 513 ₽** | 0 | **1 944 762 ₽** | **55** |
| 01.06-05.08 | починенная | +129 097 ₽ | 1 | 68 019 ₽ | 4448 |

Мораль. На растущем июле односторонняя усредняющая машина выглядит вшестеро
лучше почти по всем видимым метрикам: net выше, win rate 92% против 80%,
`max_drawdown` РОВНО НОЛЬ, RF около 1086. За два месяца она зарабатывает 41 513 ₽,
сидя на открытом минусе в 1.94 МЛН и сделав 55 сделок — то есть купила лестницу
и стояла. Реальный робот выжил только потому, что его запустили 20.07.

`max_drawdown` считается по ЗАКРЫТОЙ эквити: робот, который никогда не фиксирует
убыток (нет разворота, выход только по тейку), показывает ноль просадки при любом
размере плавающего минуса. Судить о риске такой стратегии по просадке нельзя —
только по `max_mae`. Тот же признак ловит замороженный сигнал в кампании:
одинаковый max_mae во всех строках.

Реал по журналу за 20.07-05.08: +187 034 ₽ чистыми (валовый 214 210, комиссия
27 175), то есть бэктест сломанной версии завысил вдвое — он льёт по next_bar.open
без спреда, а робот 2000 раз перешёл его маркетируемыми заявками.
