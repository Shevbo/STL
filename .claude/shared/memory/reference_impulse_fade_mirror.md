Стратегия `trader/lab/strategies/impulse_fade.py` (спецификация оператора 12.09: заявки далеко
от цены, «волосяной прокол», возврат 1/2-2/3). invert=0 фейд, invert=1 пробой.

**Вердикт 13.09 (код ea4d054, честная проба, пункты):**
- ФЕЙД: минус, сделок 28-94 за квартал — ниже порога. Мёртв.
- ПРОБОЙ RI, лидер: RIM6 −34 372 (выборка!), RIU6 +15 578, RIM5 +23 037, RIZ5 +4 980, MAE до 12 000.
  Ни одна из вариаций (1 ступень, без гейта скорости, якорь 480) не в плюсе на всех 4.
- ПРОБОЙ Si, лидер: +1 585 / +4 614 / −1 544 / +13 820; одна ступень ≈ 0. Шум.

**Как «преимущество» возникало и умирало — пять слоёв, каждый выглядел как эдж:**
1. imf4 посчитан СТАРЫМ кодом на i9 (864 строки = 12 результатов) → `code_sha` в heartbeat.
2. Стоп-заявка пробоя наливалась по уровню как лимитник: win 0.92 → 0.54.
3. Докупка ступеней мимо модели стоп-заявки (вклад 1-5%, ac7aede).
4. imf5oos: отбор предсказал 4 квартала вне выборки (69% против 15%, перестановка p<0.001) —
   и это НЕ доказывало эдж: артефакт, одинаковый во всех кварталах, даёт ту же картину.
5. Проверка субагентом (fable) нашла корень: гейт скорости мерил ход до ЭКСТРЕМУМА бара входа
   при филле внутри того же бара (заглядывание в будущее), а 0.25 ATR проскальзывания = 1-2 тика
   при медиане фитиля 110-160 пт. Реализуемо только «прокол по закрытому бару → вход по открытию
   следующего». С этим — отказ.

См. [[reference-intrabar-fill-lookahead]] — общий урок для всех стратегий.
