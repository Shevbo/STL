Стратегия `trader/lab/strategies/impulse_fade.py`: заявки висят в `lvl_amp`% средней
дневной свечи от якоря EMA(`mean_n`), исполняются проколом. invert=0 — фейд (лимитник
против прокола), invert=1 — пробой (стоп-заявка по проколу).

**1. Ловушка исполнения (12.09).** Стоп-заявка наливалась ровно по уровню, как лимитник;
на медленном якоре бар открывался уже за уровнем → «покупка» по прошедшей цене.
RIM6: +148 929 / win 0.92 → −4 584 / win 0.54 после `max(уровень, открытие)`. В зеркальном
гейте стороны исполняются РАЗНЫМИ типами заявок; `slip_atr=25` закреплён издержкой.

**2. Ловушка i9 (12.09).** Волна imf4 посчитана СТАРЫМ кодом: 864 строки = 12 результатов.
i9 тянет код только по `update_token`; `trend_detector.py` не было в манифесте. Теперь
heartbeat отдаёт `code_sha` по всему манифесту — сверять перед чтением результатов.

**3. imf5 внутри выборки (13.09, честный код, оси живые: 864 уникальных из 864).**
Гейт «плюс на ОБОИХ кварталах, ≥100 сделок»:
- ФЕЙД: RI 0, Si 0 из 864. Мёртв окончательно.
- ПРОБОЙ: RI 172, Si 211 из 864. Разрез сторон у лидеров не односторонний (Si плюсует и
  на падении SiM6, и на росте SiU6).
- НО лидеры на КРАЮ сетки: ret_pct 50/100, mean_n 1440, lvl_amp 15/40; step_count=3 и
  imp_frac=50 — максимумы своих осей. MAE лидеров ~1/5–1/6 net.

**4. Ждёт:** `imf5oos` — вся сетка на RIM5/RIU5/RIZ5/RIH6 и SiM5/SiU5/SiZ5/SiH6, обе стороны
(13 824). Критерий как в `rf_oos_gate.py`: доля переживших среди прошедших гейт обязана быть
выше, чем среди не прошедших. rich_fool умер именно здесь ([[project-rich-fool]]).
Денежный вывод — через проверку субагентом ([[feedback-validate-money-with-fable]]).
