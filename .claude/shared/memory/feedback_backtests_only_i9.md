**STRICT (20.09.2026):** любой расчёт бэктеста, перебора, плацебо и прогона по стакану идёт ТОЛЬКО на i9. Локальная Windows-машина окна и хостер под расчёт не использовать, пока оператор не скажет отдельно по конкретной задаче.

**Why:** хостер — живой прод (earlyoom убивает uvicorn=STL под нагрузкой, см. [[reference_hoster_oom_kills_stl]]), а локальные прогоны не воспроизводимы для остальных окон и съедают машину оператора. i9 — специально купленная под это железка, и она простаивает.

**How to apply:** задания ставить в очередь `backtest_runs` (engine=remote), i9 забирает их сам через `POST /api/v1/agent/claim`; агент на i9 запускает ОПЕРАТОР (`scripts/opt_agent.py`, SSH туда нет). Если i9 молчит — сказать оператору, а не считать самому. Данные для i9 едут единственным каналом `GET /api/v1/agent/bars/<key>` из `agent_bars/<key>.json` на хостере; подготовка такого файла (чтение архива, выжимка) расчётом не считается, но держать её лёгкой и потоковой. Связано: [[project_book_replay]], [[reference_i9_axis_alive_probe]], [[reference_i9_uncommitted_code]].
