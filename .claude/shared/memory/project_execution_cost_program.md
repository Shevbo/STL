30.09.2026 после ночи отпечатков оператор принял мою оценку (найти чужой алгоритм: 10-15%,
улучшить исполнение: высокая) и поставил приоритет: улучшить исполнение и модель издержек
на измеримую величину. Программа: `docs/execution-cost-program.md`.
Единица: пункты за филл и ₽/месяц при текущем обороте. Шаги: 0 базовая линия по нашим
живым заявкам (`~/market-archive/order-*.jsonl`, 46 дней с 12.08, PENDING со своей ценой →
FILLED, задержка ~100 мс = лимит по касанию, фактически тейкер; `scripts/fills_vs_model.py`);
1 поверхность издержек по стакану (`trader/lab/exec_cost.py`, минута/секунда/класс минуты);
2 политики доведения на снимках с границами наливки (`trader/lab/exec_policy.py`: market,
hold(T), hold+chase); 3 модель очереди по мс-ленте (с 01.10 лента с миллисекундами и
номером сделки, real-trade rev 1790745209); 4 передача real-trade секунд фаз профилей
(`trader/quik/exec_profiles.py`: aggressive 10+10 с, active 180+180, normal без доведения).

Вердикт fable 30.09 по шагам 0-2: (1) профили доведения (`exec_profiles.py`) применяются
ТОЛЬКО к сработавшим умным заявкам STL (3% филлов); заявки роботов раннер шлёт маркетабельно
сразу по дизайну (стоящий лимит → позиция не переворачивается → переэмит каждый бар, стекинг
видели вживую); пассивность для роботов = правка `robot_runner` с защитой от стекинга (real-trade).
(2) «hold 180 + chase 180 экономит 7-8 пт» = медиана бимодальной величины; по СРЕДНЕМУ пассивная
политика хуже рынка в каждой будничной страте (RIZ6 N=10 +6..+9 пт), границы opt/pess расходятся
на 20 пт: ранжировать по медиане нельзя. (3) базовая линия: mid из снимка с лагом до 60 с
подменяет классы размещения; 200 филлов ровно по цене заявки = 37% ₽ (цена заявки вместо VWAP
сделок или лаг); 62 тыс ₽/мес верхняя граница, ~40 нижняя. Дальше: якоря реальных заявок,
cost_MEAN, веса будни/выходные по живой доле; базовая линия v2 с возрастом снимка ≤ 3 с.

**Why:** тейкер платит 9-12 пт/филл на RI, стена комиссии; это крупнее любого найденного
эджа. Настройки живого робота меняет только real-trade.

**How to apply:** каждая цифра с ценой круга и числом филлов; границы, не точки, пока нет
очереди; выводы через fable. См. [[project-algo-footprints]], [[reference-commission-wall]],
[[reference-book-load-truth]].
