Фильтр «долина смерти» против пилы MACD в узком боковике (спроектирован и внедрён
2026-08-05, коммит 2fceadf, релиз STL 2026.08.05, runner build_rev 1785962534 —
агент применяет в 03:00).

- Детектор `dv_flags` в `trader/lab/strategies/library.py`: размах ЗАКРЫТИЙ за
  `dv_bars` минуток < `dv_range_pts` пунктов = долина. По close, не hi/lo —
  фитиль маркетмейкера долину не гасит (защита от ложного пробоя без отдельного
  параметра). O(n) деками.
- Два действия: (1) в долине отсеиваются вход с нуля, обратная нога разворота и
  доборы (выходы никогда); (2) вырезается только ХВОСТОВАЯ долина (helper
  dv_sig_window, общий для make_on_bar и explain — паритет по построению).
  Долина глубже запаса (DV_FETCH_EXTRA=480) = hold, но после пробоя сигнал жив
  СРАЗУ (сырая серия).
- БАГ v1 (чинен 07.08, коммит 43eb2ee, rev 1786080724): вырезались ВСЕ долинные
  бары истории → после ночной долины роботу не хватало прогрева ещё часы ПОСЛЕ
  пробоя на 600 пт (lxk22 нем с 22:28 до 08:21), а консоль фильтровала по всему
  хвосту и показывала «СИГНАЛ ЛОНГ». Урок: любой фильтр серии обязан жить в
  ОДНОМ helper'е для движка и explain и не зависеть от глубины fetch.
- Отличие от разножки: [[project-churn-filters]] `min_gap_pts` гейтит только
  доборы; dv гейтит и входы с нуля. Отсевы: `dv_skips` + фантомы (дедуп по
  ширине коридора; сторона разворотной ноги = want, не старая позиция).
- Зеркала: `robot_runner/explain.py` (та же фильтрация серии + `dv_block` метит
  ВСЕ entry), `host.py` шлёт dv_skips в filter_stats, карточка «Долина смерти
  отсеяла», группа «Частота» в param-groups.ts, лонгрид docs.html.
- НЕ для стратегий на времени бара (pivot) — вырезание рвёт серию по времени.
- Стартовая прикидка для MACD·RIU6 (lxk22tsffsxiiotb8kmpsato): dv_bars=60,
  dv_range_pts=400 — подобрать перебором (оси уже в Optimizer/кампаниях).

**Why:** живая пила 22.07 (200 сделок в коридоре 86 700-87 200) съедала депо
комиссией; разножка этот случай не закрывала.
**How to apply:** дефолт 0/0 = выкл; включать параметрами робота, до агента
доезжает только с пересборкой robot-runner.exe + publish.
