Начато 23.09.2026. Экран «Backtest Lab» переделывается в интерактивный запуск и разбор прогонов. ТЗ оператора: (1) при выборе стратегии видны все её прогоны с датами, параметрами и финрезами; (2) ожидание дольше 10 с объясняется и показывает прогресс-бар; (3) «Системный монитор прогона» становится ИИ-ассистентом в контексте выбранной стратегии и показанных прогонов; (4) под монитором область, куда ассистент по запросу выводит кривую доходности.

**Канал LLM — Lineman**, оператор подтвердил 23.09 (в ТЗ он писал «Claude Sonnet через OAuth», но подтвердил Lineman). См. [[feedback_llm_via_lineman]].

Спека дизайна: `docs/lab-runs-screen-spec-v1.md` в git (сделана окном backtests по заказу оператора).

**Факты, определяющие конструкцию:**
- У строк кампаний в `optimization_leaderboard` НЕТ сделок и кривой — их хранит только лучшая комбинация прогона. Поэтому клик по строке = постановка одиночного прогона тем же вектором, с прогрессом и очередью i9, а не молчаливый дорасчёт. `openRun` сейчас сам зовёт `rerunFromChart` — это убрать, иначе 20 кликов = 20 заданий на i9.
- `net_profit` в лидерборде — РУБЛИ только если у строки заполнен `point_value`; пусто (синтетические символы вида `spRIZ6d0921`) — это ПУНКТЫ. Единицу брать из строки. См. [[reference_point_coef_trap]].
- Список прогонов читать из `backtest_runs` (19k строк, индекс `(strategy, created_at DESC)` есть), а не из витрины кампаний: одиночные пересчёты витрина не видит.
- В UI запрещён свободный поиск подстрокой по `campaign_run`: ведущий `%` = полный скан, это и грузило хостер до LA 31.

**Ассистенту запрещено** оценивать стратегию по строке лидерборда («хорошая ли стратегия») — строка это подгонка; у backtests на таких выводах сгорели недели, трижды за сутки выводы оказывались артефактом. Проверка: числа ответа сверяются с числами контекста, чужое подсвечивается.

Окно backtests даёт: (а) функцию «строка лидерборда → вектор параметров для одиночного прогона» — запрошена первой; (б) словарь человеческих подсказок по параметрам из `library.py` для цитирования ассистентом; (в) читаемые названия кампаний.
