02.10.2026 оператор прислал скриншот `m.html` с iPhone (вьюпорт 390 px): значения ВМ видны наполовину ЗА правым краем карточки, чип «журнал +3» обрывается, подпись «дефекты кода, не торговля» строится лесенкой по одному-два слова. Его слово — «кривой».

**Причина не в ширинах, а в модели флекса:** у флекс-детей `min-width` по умолчанию `auto`, то есть ребёнок не может стать уже своего содержимого. В строке позиции стояли четыре неразрывных куска — «Роботы 0 ср. 9 891», «Ручные −23 ср. с клиринга 85 300», чип расхождения и само число с `white-space: nowrap`. Их сумма превышала 374 px, и строка переставала помещаться в экран. Каждый кусок по отдельности был обоснован (число, разорванное переносом, читается как другое число), поэтому «убрать nowrap» решением не было.

**Контракт раскладки (разбор с fable, применён 02.10.2026):** строка — `display: grid`, `grid-template-columns: minmax(0, 1fr) fit-content(45%)`. Текст получает право ужаться до нуля (ноль в `minmax` — это и есть право), число получает ширину первым и не переносится никогда. Все уточнения уходят `grid-column: 1 / -1`, то есть собственным рядом во всю ширину — лесенка исчезает сама. Распорку `.sp` флекс-времён гасим правилом `.row > .sp { display: none }`, а не правкой десятка строителей строк: лишний пустой элемент сетки сдвинул бы число в третью колонку. Подпись «что это за число» (ВМ сессии, фикс + ВМ) — `<small>` ПОД числом, сбоку она отнимала ширину у текста.

Второй замок поверх `nowrap`: деньги печатать с НЕРАЗРЫВНЫМИ пробелами (`\u00a0` в разделителе тысяч и перед `₽`).

**`overflow-x: hidden` ставить нельзя** — он прячет следующий такой же баг вместо того, чтобы его показать. Раскладку нечем проверить вычислением (в jsdom нет layout), поэтому тестами стережём САМ КОНТРАКТ: наличие `grid`, `minmax(0, 1fr)`, `min-width: 0` у детей, `nowrap` у значения, отсутствие `overflow-x: hidden`.
