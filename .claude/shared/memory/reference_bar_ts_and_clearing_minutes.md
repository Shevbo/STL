Проверено по `agent_bars/RIZ6.json` 23-28.09.2026 (30.09): бары помечены НАЧАЛОМ минуты
(10:00 пиковая, 23:49 последний бар дня, 23:50 нет). В минутах 14:00-14:05 и 18:45-19:05
стоят бары с реальными сделками (14:01 24.09 = 588 лотов; 19:05 28.09 = 329), то есть
константы «клиринг = пауза торгов» в анализах (a4_bar_boundary исключал их) отсекают
живые минуты. Первые бары дня с 08:58, выходные с 10:00 и тонкие.
10:00 несёт 4.6x медианного объёма дня на RI/Si (2.9x BR), 14:00 2.3-2.8x, 19:00 1.2-1.9x.

**Why:** проверка fable по A4 нашла, что «бар 14:00 с объёмом при клиринге» рушит либо метку,
либо константы; по данным рушатся константы. Правило [[feedback-moex-schedule-truth]]:
расписание только официальное, «закрыто» не заявлять из эвристики.

**How to apply:** в модулях отпечатков исключения клирингов только параметром (по умолчанию
выключены); минуту дня считать от метки как от начала; 10:00/14:00/19:00 = событийные минуты,
которые надо отделять от «границ баров» (см. [[project-algo-footprints]]).
