02.10.2026 перепрогон защиты «радиации» в боевой семантике real-trade (защита выкачена ed4ee8b:
K считается как НАБОР |позиция|/лот >= K, отход X% с одной стороны, плюс перевзведение той же сетки
через N минут после чистого выхода с базой по текущей цене; grid_sim b048258/6cc00f4,
`docs/grid-regime-filter-2026.md`). Живые наборы оператора на отложенной трети, тейкер: без защиты
−288/−399/−366 тыс ₽; защита K=3 + X 0.25% без перевзведения −20/−24/−23 тыс, 92% выходов по
безубытку, лучше случайного включения режима 20 из 20; с перевзведением через 15 мин −203/−233/−232,
через 60 мин −109/−112/−118 (3.7-9.1 перевзведений в день). При K=5 или без X трактовка «набор» хуже
трактовки «все филлы» (10/10: −136 против −42). Real-trade и оператору рекомендовано перевзведение
выключенным; решение оператора открыто, как и включение защиты на живых сетках 41bf3af0dd, f110ea7e13.

**How to apply:** при разборе живых сеток проверять, включено ли перевзведение; бэктест защиты считать
только в боевой семантике (k_mode=net). См. [[project-grid-protection-trigger]].
