Память окна (`memory/*.md`) — это и есть вход в RAG: файл попадает в индекс как `.claude/shared/memory/...` после `bash scripts/memsync.sh push` плюс `git push`, и становится виден примерно через 20 минут. Писать я туда писал, а **читать почти не читал: A/T моего окна на 01.10.2026 = 9 поисков в RAG из 2129**, то есть 0.4 %, и за всю сессию про три косяка с заявками я не задал RAG ни одного вопроса, пока оператор не спросил напрямую. K по федерации 0.003, окон с оценкой автора 4+ — ноль из 21.

**Why:** в тот день я сутки добывал руками то, что лежало в индексе. Класс бага «кап таблицы режет живое» был записан 26.09.2026 в `accounts.go` («ПОЧЕМУ ПЯТИСОТ МАЛО»: кольцо сделок — единственный путь, которым факт торговли доезжает до STL), и `rag_search` отдаёт эту запись по запросу про обрезку таблицы хвостом. Я нашёл тот же класс только из ревью fable, часами позже и уже после того, как выложил неполную правку. Шестисекундный поиск стоил бы дешевле.

**How to apply:**
* **«Почему / где решили / что кусало раньше / а работало ли вообще»** → `rag_search` ПЕРВЫМ, до grep и до чтения файлов. Это единственный инструмент, который находит прозу, runbook'и, историю решений, инциденты и канон федерации.
* **Точный символ, имя функции, импорт, путь** → `grep`/`Glob`. Шестисекундный семантический поиск за символом проигрывает `grep` за 0.2 с.
* Файл читать — чтобы править, отлаживать конкретные строки или после того, как `rag_search` на него указал.
* Лестница глубины: `snippet` (по умолчанию) → `chunk` → `file` → `context`. Начинать с дешёвой.
* `NO MATCH` значит нет совпадения, а не отсутствие факта (recall@3 ~72 %): сказать прямо, читать источник, НЕ выдумывать.
* Индекс — снимок; для файлов, правленных в этой сессии, верить рабочему дереву.
* **После каждого поиска — `rag_feedback`**, честно, свои записи оценивать так же строго, как чужие. `content`+`benefit` формируют оценку АВТОРА найденного файла, то есть соседнего окна; `speed` берётся из `[N ms]` в ответе.
* Перед новой правкой в живой торговле: один вопрос вида «что кусало раньше в <подсистеме>» дешевле любого ревью.
