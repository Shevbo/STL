`BarBuilder.TAPE_PRIORITY_MS = 30_000` (`robot_runner/bars.py`): пока идёт лента
всех сделок, снимки-котировки заглушены, но стоит ленте замолчать на 30 секунд —
бары снова строятся из bid/ask/last, то есть из ЗАМЕРШЕЙ цены. На стоящей бирже
за ночь набегают сотни плоских минут. Виджет-график компаньона всю ночь рисовал
по ним свечи (08.08.2026).

Починено 09.08.2026 (коммит cb4dee4, runner rev 1786259651):
- `Bar.traded` (`trader/lab/runtime.py`, дефолт True — бары бэктеста/ISS это факт
  биржи); `_merge` ставит метку по источнику и только ВЗВОДИТ её: минута,
  начатая котировкой и продолженная сделкой, настоящая, поздний тик факт сделки
  не стирает.
- `BarBuilder.traded_bars()` -> `host.py` bars_tail.
- **Фильтруется ХВОСТ, а не билдер**: `on_bar` и `explain` читают тот же
  `bars()`, вход стратегии не меняется. Правка билдера была бы правкой ТОРГОВЛИ.
- Метка переживает рестарт: `to_rows` дописывает 7-ю колонку, `seed` читает её,
  строку старого формата (6 колонок) считает настоящей — иначе первый рестарт на
  старом state спрятал бы у панели всю историю. Откат версии безопасен: старый
  `seed` читает строку по индексам 0..5.

Сопутствующее (зона UI, коммит ead6f06): `health.exchange_lag_ms == -1` это
СИГНАЛ «ни одной сделки не видели» (`quik_agent/internal/accounts/accounts.go`,
Lua `last_trade_ts_ms == 0`), а не отрицательные миллисекунды. Вычитание его как
числа объявляло молчащую ленту самой свежей.

**Why:** нарисованная свеча на стоящей бирже это ложь на экране; а любая правка
входа стратегии ради картинки — это правка торговли.
**How to apply:** нужен показ баров человеку — бери `traded_bars()`. Диагностируя
«странные ровные минутки», сначала смотри, шла ли лента.
