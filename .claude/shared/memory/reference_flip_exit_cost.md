18.09.2026. Гипотеза оператора «выходить по стопу, а не по перевороту MACD» проверена на минутках 2022-2026 по контрактам (`scripts/exit_rule_sweep.py`, `flip_block_matrix.py`, `si_flip_controls.py`, `si_invert_control.py`).

**Флип — измеренные издержки, а не сигнал.** Блок переворота (`flip_min_pts` заведомо больше хода; выход только по тейку/стопу) улучшил итог в 12 клетках из 12 на RI/Si/GD/BR × macd/2EMA/3EMA; филлов меньше в 5-20 раз. На боевой спеке lxk22: −1.49 млн пт → +225k, парный t=+2.40 по 17 контрактам. НО большая часть этой разности — тождество «торговать в 18 раз реже дешевле», поэтому t тут не аргумент, важны знак и повсеместность. Уровень остаётся нулём везде, кроме Si, и **в 2026 году разность отрицательная** — живого робота менять не на чем.

**Асимметричные версии хуже полного снятия** (ось `flip_hold_win`, по умолчанию 0): держать прибыльную −892k, держать убыточную −1.83 млн против +225k у полного блока. Версия «флип забирает прибыль раньше тейка» опровергнута.

**Si: зарабатывает класс, а не стратегия.** 2EMA +92652 пт, 3EMA +84021 (пункт Si = 1 руб, ГО 13408). Плацебо из 60 случайных трендовых правил с тем же выходом: медиана +55598, 95-й перцентиль +103945 — наши внутри облака (p=0.117 и 0.183), пререгистрированный порог не пройден. Инверсия сигнала при том же выходе даёт −120k, то есть сигнал важен, «плюс от формы тейк/стоп» опровергнуто. Граница класса: медиана плацебо RI +21126 пт, GD −5676 — не универсально.

**Экономика без приукрас:** ГО это не капитал (просадка 22440 пт = 1.7 ГО ликвидирует счёт с одним ГО). На капитале ГО + 2 просадки медиана класса ~17% простых в год, 2EMA ~28% — около ключевой ставки периода. Искать «лучшую» стратегию внутри класса бессмысленно: разброс случайных правил шире разницы между ними.
