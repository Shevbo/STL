01.10.2026 оператор задал схему (лонг, шорт зеркально): после импульса вверх лимит на покупку
половины у N-минутной средней, вторая половина на X% зеркала (E2 = E1 − X%·(P − E1)), стоп на S
пунктов ниже второго входа, тейк обоих на Y% от первого пика (T = E1 + Y%·(P − E1)). Пререгистрация
`docs/scale-in-retest-2026.md`, модуль `trader/lab/strategies/scale_in.py` (dc5b1e6, Sonnet).
Первая сетка (imp 3-5 ATR, N 5-60, X 20-100, S 50-600, Y 50-120; 9 408 × 4 контракта 2026, 73 мин
i9): плюсовых 5.2%, лучший 50/60/40/600/90 +35/−12/+97/+3 тыс по RIH6/RIM6/RIU6/RIZ6, лонг −112 тыс,
шорт +18; НО против случайного момента дня лучший вектор выше в 20 из 20 розыгрышей (в отличие от
ретеста, импульс здесь несёт информацию), и лучшие точки на краю сетки по трём осям.

**Why:** оператор: «исходная сетка была твоим бредом». Мои сетки по умолчанию брали «привычные»
диапазоны (N до 60, импульс до 5-10 ATR) вместо диапазонов из логики схемы; оптимум на краю =
сетка не охватила задачу.

**How to apply:** диапазоны сетки выводить из масштаба явления (медленная средняя для отката
крупного импульса = сотни минут), край первой сетки = обязательное расширение до вердикта.
Расширенная сетка (a177317): imp_min 5-12 при imp_max 15 ATR, imp_bars 10/30, N 60-400, S
600-1600, wait_bars 240; результат вписать в документ. Реализуемость: висящие лимитки раннер
снимает каждый бар, для боя нужна правка раннера (real-trade). См. [[project-retest-strategy]].
