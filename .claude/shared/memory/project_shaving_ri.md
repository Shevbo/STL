Стратегия `trader/lab/strategies/shaving_ri.py` (id `shaving_ri`), стенд
`https://stl.shectory.ru/shaving-ri.html` (артефакт `shaving-ri-sweep.json` в
`frontend/dist/`, генерит `scripts/shaving_ri_sweep.py` на хостере).

**Механизм, который переиспользуется:** `BacktestRuntime(extra={...})` — опорные
серии, которые стратегия ЧИТАЕТ, но не торгует; `get_bars(symbol)` маршрутизирует
по символу так же, как это уже делал `LiveRuntime`, поэтому спред-стратегия это
один и тот же код в бэктесте и вживую. Опорные бары режутся bisect'ом по времени
ТЕКУЩЕГО бара. В API подключается через `_fetch_extra_for_backtest` по параметру
`basket`. `load_bars_iss` знает индексные secid (`INDEX_SECIDS = {RTSI, IMOEX}`,
движок stock/index).

**Доказано, а не заявлено (01.08.2026):** RTSI ДОЛЛАРОВЫЙ. Дневная корреляция
врёт (закрытия TQBR/индекса/USD-RUB это три разных момента, рублёвая корзина
показала 0.904 против 0.871 у долларовой). Решающий тест по УРОВНЯМ:
`IMOEX/(RTSI×USDRUB)` СКО/сред = 0.0071 против `IMOEX/RTSI` = 0.0368, разброс
в 5.2 раза меньше. Значит RI и RTSI оба долларовые, отношение RI/RTSI от курса
не зависит, валютная нога не нужна. Проверка: `scripts/shaving_ri_basket_check.py`
(эндпоинт `analytics/RTSI` СТРАНИЧНЫЙ, без пагинации собирает 20 бумаг на 39%
веса и даёт фальшивую корреляцию).

**Результат прогона: ПРЕИМУЩЕСТВА НЕТ.** 100 комбинаций, RIU6 vs RTSI,
01.05-31.07.2026: прибыльны 17 из 98 со сделками, медиана −12 111 ₽, сумма по
сетке −1.3 млн ₽, лучшая +9 308 ₽ на 24 сделках. Контроль на чистом июле
(ближний контракт, `?src=shaving-ri-sweep-jul.json`) ХУЖЕ: 12 из 96, медиана
−7 565 ₽. Одиночный лидер в убыточной сетке = подгонка. В реал не выводить без
второй ноги. Ср. [[reference-ob-bru6-no-edge]].

**Почему идея в исходном виде не работает:** торгуется ОДНА нога, поэтому
результат = отклонение + движение самого рынка, и второе это голый направленный
риск. Плюс окно задаёт корзина: индекс РТС считают только в сессию акций
(~10:00-18:45 МСК, ~530 минут в день), FORTS до 23:50. Плюс базис фьючерса
дрейфует (отношение RI/RTSI за 3 месяца 96.3…102.0), поэтому ось X это EMA
самого отношения, а не ноль.
